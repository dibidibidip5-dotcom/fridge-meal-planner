# 우리 집 냉장고 · 한 주 식단

냉장 · 냉동 · 김치 · 실온 재고와 한 주 식단을 한 페이지에서 관리하는 웹페이지입니다.

- **냉장고 재고**: 칸별(냉장/냉동/김치/실온) 수량 조절, 유통기한 D-day 표시
- **장보기 붙여넣기**: 장본 목록을 여러 줄로 붙여넣으면 한 번에 재고로 추가
- **한 주 식단표**: 보유 재료와 매칭되는 메뉴 추천, 원클릭 식단 추가
- **장보기 메모**: 식단에 필요한데 재고에 없는 재료만 자동 추출

## 쓰는 법

아이폰 사파리에서 아래 주소를 연 뒤 **공유 → 홈 화면에 추가**를 누르면 앱처럼 열립니다.

<https://dibidibidip5-dotcom.github.io/fridge-meal-planner/>

입력한 재고와 식단은 서버로 전송되지 않고 **그 기기의 브라우저 저장소(localStorage)에만** 저장됩니다. 기기를 바꾸거나 백업하려면 화면의 **JSON 내보내기**를 사용하세요.
